# Admin Dashboard Scope (Web)

## Mandatory modules
- User/Host/Agency management with role filters
- KYC queue (approve/reject with evidence)
- Coin economy config (packages, gift values, call rates)
- Commission controls and payout freeze override
- Withdrawal review queue with anti-fraud signals
- Real-time moderation monitor + strike controls
- Revenue KPI dashboards + weekly/monthly exports (CSV/PDF)
- Multilingual UI with RTL-compatible layout

## Suggested frontend stack
- Next.js + TypeScript + Tailwind + i18next
- Recharts/ECharts for KPI visuals
- WebSocket hooks for live monitoring cards
