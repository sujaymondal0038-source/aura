# Flutter Mobile App Scope

## Core tabs
- Home (live host cards + previews)
- Calls (1v1 paid sessions)
- Wallet (coin purchase, balance, history)
- Inbox/Notifications
- Profile (language, favorites, security)

## Host mode
- Go Live controls
- Earnings dashboard
- Target progress and leaderboard
- Withdrawal requests

## UX requirements
- Dark premium theme with neon gradients
- Animated coin balance and gift overlays
- One-tap join live/call CTA
- Full RTL adaptability
